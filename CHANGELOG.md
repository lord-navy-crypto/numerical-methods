# Changelog

All notable changes are recorded here. This project follows semantic versioning.

## [1.2.0] - 2026-08-27

### Added

- Normalized error and stable diagnostic status classifications
- Scan summaries for RMS, median, maximum, worst x, pass rates, and reliability
- Reproducibility report export in JSON
- Full GitHub community metadata, MIT license, notices, and citation metadata
- Tests for new diagnostics and scan summaries

### Changed

- Renamed the interface to Numerical Error Analysis Studio
- Standardized every result page as plots, key metrics, then complete data
- Expanded English documentation and numerical limitations
- Hardened configuration validation and CI permissions

## [1.1.0] - 2026-08-26

- Added mpmath high-precision references and false-convergence detection
- Added float32/float64 scans, CSV exports, tests, and launchers
